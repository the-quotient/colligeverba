ColligeVerba

Bridging the gap between transcription and dictionary lookup.

How to use ColligeVerba is a blazingly fast online tool that assists you while transcribing handwritten Latin and historical German source texts by searching for word forms using Regular Expressions. Read more...

When to use it: When you encounter words that are very difficult to read – especially if the first letter is indecipherable – making standard dictionary lookups almost impossible. ColligeVerba bridges the gap by letting you search using only the letters you can actually read.

Step by step:

  • Search: Enter the letters you can read and mark unknown ones with a question mark (?). If you are unsure whether a sign represents one or two letters, use two question marks (??). For German one question mark currently represents always one or multiple characters.
  • Refine: Once you type a ?, click the "or" button on the blue tile that appears to add several possible character candidates for that missing letter.
  • Explore (Latin): Click a result to open a form analysis and translation suggestions powered by latein.me.
  • Explore (German): Click a result to jump directly to that exact word's entry in your selected dictionary on the woerterbuchnetz.de.
